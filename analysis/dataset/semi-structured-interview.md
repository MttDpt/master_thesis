# Feedback loop

# Section 1 — First Impressions

- What did you think about the ambient layer overall?

   - Prompt: What stood out to you the most?

   - Prompt: What did you like or dislike about it?

- How did the ambient layer make you feel while driving?

- Prompt: Did it feel calm, engaging, distracting, pleasant, overwhelming, or something else?

- Prompt: Can you describe that feeling in your own words?

# Section 2 — Preference and Comparison

- Would you prefer an interface with this kind of ambient layer, or a more standard interface without it? Why?

   - Prompt: What makes you prefer one over the other?

   - Prompt: In which situations do you think one would work better than the other?

- Would you rather have ambient information presented through this 3D world, or shown only through a conventional UI without the ambient layer? Why?

   - Prompt: Which option feels more intuitive to you?

   - Prompt: Which one feels more useful?

- Which option do you think is less distracting and more suitable for driving? Why?

   - Prompt: Did one feel easier to process at a glance?

   - Prompt: Did one feel safer or more comfortable while driving?

# Section 3 — Personalisation and Control

- Would you want to personalise or change anything about the ambient layer?

   - Prompt: If yes, what would you change?

   - Prompt: How would you like to change it?

   - Prompt: Are there elements you would remove, simplify, or make more noticeable?

# Section 4 — Information and Data Mapping

- You saw the ambient layer react to three different types of data. Are there any other types of information you would like this 3D world to respond to?

   - Prompt: What kinds of driving-related information would be useful to represent this way?

   - Prompt: Are there any data points that you think should not be shown in this form?

- Why would those additional data points be meaningful or useful to you?

   - Prompt: In what situations would they help?

- Prompt: How would you expect the environment to react to them?

- Section 5 — Closing Reflection

- Overall, do you think this kind of ambient layer could have a place in a real driving experience? Why or why not?

   - Prompt: What would need to improve for it to work well in practice?

   - Prompt: Who do you think would benefit most from it?

- Is there anything else you would like to add about your experience that we have not covered?

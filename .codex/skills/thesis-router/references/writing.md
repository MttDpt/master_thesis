# Writing routing

- Draft or revise thesis prose: `wr-general` plus the matching `wr-*` chapter skill.
- Abstract: `wr-abstract`; Introduction: `wr-introduction`; Background/related work: `wr-background`; Design and Methodology: `wr-methodology`; Results: `wr-results`; Discussion: `wr-discussion`; Conclusion/future work: `wr-conclusion`.
- Shared paper-derived principles live in `wr-general`; read its `references/source-map.md` only for provenance or differing source advice.
- Use approved reports as evidence directly; do not invoke `da-report` unless a standalone analytical report is requested.
- Add `da-explainer` when an analytical concept needs explanation, and `gen-adversarial-reviewer` when a sceptical review is requested.
- Apply prose to TeX: `overleaf-local-edit`, then `overleaf-build-audit` for the affected output.
- Use `overleaf-maintenance-audit` for a requested completed-chapter or whole-thesis audit.
- Synchronise only when requested.

Load each skill once per task; do not load all chapter skills or the full analysis history.

# Analysis routing

Choose the requested capability:

- `da-preprocessing`: maintain confirmed shared preprocessing rules.
- `da-rq-contract`: maintain confirmed RQ-specific definitions and boundaries.
- `da-review`: choose or reconsider an analysis method.
- `da-code`: implement and validate an approved analysis; add `da-code-rules` for Python.
- `da-report`: create a standalone report from an existing validated package.
- `da-explainer`: explain unfamiliar concepts or interpret study evidence.
- `gen-adversarial-reviewer`: perform a requested sceptical audit.

Combine capabilities only when the task requires their outputs. Interpreting approved findings or drafting thesis prose does not trigger method selection, recomputation, or a separate report. Use `wr-general` and the matching chapter skill for prose; use the Overleaf map only when applying changes to the paired checkout.

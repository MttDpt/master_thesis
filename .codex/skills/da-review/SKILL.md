# Choose an Analysis Method

Use when the user asks to select or reconsider an analytical method. Interpretation of approved findings does not reopen method selection.

1. Identify the question, available evidence, unit of analysis, denominator, missingness, and study-design constraints.
2. Compare the smallest set of methods that could answer that question. Explain the trade-off that changes the decision; reject unsupported causal or predictive claims directly.
3. Recommend the simplest defensible approach and its interpretation boundary. Request a decision only for an unresolved choice that would change the analysis.

Survey the full descriptive, comparative, associational, predictive, temporal, qualitative, mixed-methods, causal, exploratory, and confirmatory landscape only when explicitly requested.

Use `da-explainer` for unfamiliar concepts. Record user-confirmed RQ decisions through `da-rq-contract` and shared preprocessing decisions through `da-preprocessing`; `da-code` owns approved implementation.
